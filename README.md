# single-axis-solar-tracking-system
Designed and implemented a single-axis solar tracking system using Arduino and LDR sensors to automatically align solar panels toward sunlight, improving power generation efficiency.
## Overview
This project is an Arduino-based system designed to automatically track sunlight and align solar panels for maximum power output.

## 🎯 Objective
- Design a low-cost solar tracking system
- Increase energy efficiency compared to static solar panels
- Automate panel movement using sensors

## ⚙️ Components Used
- Arduino UNO
- LDR Sensors (Light Dependent Resistors)
- Servo Motor
- Solar Panel
- Connecting Wires

## 🧠 Working Principle
- The LDR sensors detect sunlight intensity.
- The Arduino controls the servo motor to adjust the panel angle toward the brighter direction.
- Real-time adjustment improves the panel’s power output by up to 20%.

## 🧰 Tools & Technologies
- Arduino IDE
- Embedded C
- Circuit Prototyping (Breadboard)
